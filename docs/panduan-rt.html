PANDUAN SINGKAT ADMIN RT

Alamathttps://mantup.biz.id/data-warga/Nama penggunadari Admin Desa (mis. admin10)Kata sandidari Admin Desa

Akun Admin RT hanya bisa melihat dan mengubah data RT-nya sendiri. Laporan yang dicetak otomatis berjudul RT Anda.

1

Masuk

Buka alamat di atas di Chrome (HP atau laptop), isi nama pengguna & kata sandi dari Admin Desa, tekan Masuk. Di pojok kiri atas tertulis RT Anda (mis. RT 10 · Mantup).

2

Ganti kata sandi

Menu ☰ → Pengaturan → tab Akun & Server. Isi kata sandi lama dan baru (minimal 8 huruf/angka), tekan Ganti. Di bagian Pengguna Anda juga bisa membuat akun untuk pengurus (bisa mengisi data) atau pembaca (hanya melihat laporan).

3

Buat Dasawisma

Pengaturan → tab Dasawisma → Tambah Dasawisma → isi nama → Simpan. Bila Anda mengimpor file Excel (langkah 4), dasawisma di file itu dibuat otomatis.

4

Isi data warga dari file Excel lama

Menu Impor / Ekspor → klik kotak hijau → pilih file Excel data warga RT Anda (.xlsm / .xlsx). Periksa jumlah warga & keluarga yang terbaca, lalu tekan Simpan hasil impor. Peringatan kuning hanya catatan — data tetap masuk dan bisa dirapikan nanti.

5

Atau tambah / ubah warga satu per satu

Menu Data (Data Warga) → Tambah, atau tombol + ungu di bawah. Isi nama dan data lain, tekan Simpan. Untuk mengubah, tekan Ubah pada kartu warga. Warga yang dihapus masuk Tempat Sampah dan bisa dipulihkan.

6

Mencetak laporan

Menu Laporan → pilih laporan → atur tanggal / bulan bila perlu → tab Lembar cetak → Cetak / PDF. Tombol Excel mengunduh tabelnya sebagai file Excel.

7

Bila tanpa internet

Setelah pernah masuk sekali, aplikasi tetap bisa dibuka tanpa sinyal. Perubahan disimpan di HP dan terkirim sendiri saat online lagi. Bila lama tidak ada sinyal, buka Impor / Ekspor → Ekspor data RT lalu kirim file .siwarga lewat WhatsApp ke Admin Desa.

Penting: ① Jangan menghapus data browser / “Hapus data situs” selama di atas tertulis “… menunggu”. ② Lupa kata sandi → minta Admin Desa mengatur ulang. ③ Pasang di layar HP: Chrome → menu ⋮ → Tambahkan ke layar utama.

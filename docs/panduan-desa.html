PANDUAN ADMIN DESA & ADMIN RT

Alamathttps://mantup.biz.id/data-warga/Admin DesadesaAdmin RTadminXX (dibuat Admin Desa)
A. Siapa bisa apa
AkunBisa apa
Admin DesaMembuka, mengisi, dan mengubah data semua RT (01–17). Membuat akun tiap RT. Mencetak laporan per RT dan gabungan Desa Mantup. Mengimpor file data dari RT.
Admin RTSama seperti admin sebelumnya, tetapi hanya RT-nya sendiri. Data RT lain tidak terlihat sama sekali (dijaga oleh server).
Pengurus (editor) RTMengisi dan mengubah data RT-nya.
Pembaca (viewer) RTHanya melihat laporan RT-nya.

Data RT 08 yang sudah ada otomatis menjadi milik RT 08. Akun lama (admin, viewer, kader, juri) tetap bisa masuk seperti biasa.

B. Menyiapkan Admin Desa (sekali saja)
1

Masuk sebagai admin RT 08, buka Pengaturan → Akun & Server

Di bagian Pengguna RT 08 muncul kotak kuning “Belum ada akun Admin Desa”. Klik Buat Admin Desa.

Yang dikerjakan sistem: tombol ini hanya ada selama belum ada Admin Desa. Setelah dibuat, hanya Admin Desa yang bisa membuat Admin Desa lain.
2

Isi kata sandi lalu Simpan

Nama pengguna sudah terisi desa (boleh diganti). Kata sandi minimal 8 huruf/angka. Setelah itu keluar, lalu masuk dengan akun desa.

C. Kelola RT
3

Menu Kelola RT (Desa)

Berisi jumlah warga & KK seluruh desa, berapa RT yang sudah mengisi, daftar laporan gabungan, dan kartu RT 01–17 (jumlah warga, terakhir diperbarui, akun-akunnya).

4

Membuat akun Admin RT

Pada kartu RT, klik Buat akun. Nama pengguna otomatis adminXX (mis. admin09). Pilih peran (Admin RT / Pengurus / Pembaca), isi kata sandi, Simpan. Berikan nama pengguna & kata sandi itu kepada pengurus RT tersebut.

5

Pindah membuka data RT lain

Di menu samping ada kotak kuning “Buka data [RT ..]”. Pilih RT, lalu semua menu (Data Warga, Keluarga, Laporan, dll.) menampilkan data RT itu. Data yang ditambahkan masuk ke RT yang sedang dibuka. Bisa juga lewat tombol Buka data pada kartu RT.

Yang dikerjakan sistem: setiap perubahan oleh Admin Desa tercatat di Riwayat Perubahan RT tersebut dengan nama Admin Desa.
D. Laporan gabungan Desa Mantup
6

Pilih “Gabungan DESA MANTUP”

Buka laporan dari menu Laporan atau dari daftar di Kelola RT. Di atas laporan ada pilihan RT .. / Gabungan DESA MANTUP. Untuk laporan rekap, setiap RT menjadi satu baris dan baris terakhir adalah JUMLAH desa. Klik angka untuk melihat nama-namanya.

7

Laporan daftar nama: ada kolom RT

WUS, PUS, Anak 6–18, Penduduk 15–59, Register Kelahiran, dan Pencatatan Ibu Hamil/KB menampilkan semua RT berurutan dengan kolom RT. Pilihan RT di kotak pengaturan bisa dipakai untuk menampilkan satu RT saja. Tombol Cetak / PDF dan Excel bekerja seperti biasa.

Laporan gabungan tersedia untuk: Rekap Catatan Data & Kegiatan (RT), Rekapitulasi Ibu Hamil/Melahirkan/Nifas, Inventarisasi Kampung KB (isian manual = jumlah semua RT), WUS, PUS, Anak 6–18, Penduduk 15–59, Register Bayi Lahir & Kematian, Pencatatan Ibu Hamil/KB/PUS. Laporan per keluarga/per dasawisma tetap dibuat per RT.

E. Kirim data lewat file (untuk RT yang offline)
8

Admin RT: Impor / Ekspor → Ekspor data RT

Menghasilkan satu file, mis. RT09_2026-11-07.siwarga. Kirim lewat WhatsApp atau flashdisk ke Admin Desa.

9

Admin Desa: Impor file data RT → periksa pratinjau → Terapkan

Sebelum disimpan tampil ringkasan: Baru, Berubah, Sama, Server lebih baru (tidak ditimpa), dan Hanya di server (tidak dihapus kecuali dicentang). Hanya RT pada file yang diperbarui.

Yang dikerjakan sistem: sebelum impor, server menyimpan cadangan otomatis (5 terakhir per RT). Bila keliru, buka Impor / Ekspor → Cadangan otomatis → Kembalikan. Admin RT hanya bisa mengimpor file RT-nya sendiri.
F. Tanpa internet (offline)
10

Pasang di HP & tetap bisa dibuka tanpa sinyal

Buka alamat aplikasi di Chrome HP → menu ⋮ → Tambahkan ke layar utama. Setelah pernah masuk sekali (online), aplikasi bisa dibuka walau tanpa internet: data terakhir tetap tampil, ikon awan dicoret dan tertulis Offline · N menunggu bila ada perubahan yang belum terkirim.

Yang dikerjakan sistem: perubahan disimpan di HP dan dikirim otomatis begitu internet tersambung lagi. Jangan menekan Keluar selama masih ada perubahan yang menunggu (sistem akan menolak supaya data tidak hilang). Pindah RT (Admin Desa) hanya bisa saat online.
G. Saat memperbarui server di cPanel

1) Cadangkan folder data (isi database) dulu. 2) Hapus dist, server, app.cjs, package.json lama. 3) Upload & Extract zip baru. 4) RESTART di Setup Node.js App. Database lama otomatis diubah menjadi multi-RT (semua data lama = RT 08) tanpa ada yang hilang.

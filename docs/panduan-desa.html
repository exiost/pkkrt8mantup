A. Siapa bisa apa
AkunBisa apa
Admin PadukuhanMembuka, mengisi, dan mengubah data semua RT (01–17). Membuat akun tiap RT. Mencetak laporan per RT dan gabungan Padukuhan Mantup. Mengimpor file data dari RT.
Admin RTSama seperti admin sebelumnya, tetapi hanya RT-nya sendiri. Data RT lain tidak terlihat sama sekali (dijaga oleh server).
Pengurus (editor) RTMengisi dan mengubah data RT-nya.
Pembaca (viewer) RTHanya melihat laporan RT-nya.

Data RT 08 yang sudah ada otomatis menjadi milik RT 08. Akun lama (admin, viewer, kader, juri) tetap bisa masuk seperti biasa.

B. Menyiapkan Admin Padukuhan (sekali saja)
1

Masuk sebagai admin RT 08, buka Pengaturan → Akun & Server

Di bagian Pengguna RT 08 muncul kotak kuning “Belum ada akun Admin Padukuhan”. Klik Buat Admin Padukuhan.

Yang dikerjakan sistem: tombol ini hanya ada selama belum ada Admin Padukuhan. Setelah dibuat, hanya Admin Padukuhan yang bisa membuat Admin Padukuhan lain.
2

Isi kata sandi lalu Simpan

Nama pengguna sudah terisi padukuhan (boleh diganti). Kata sandi minimal 8 huruf/angka. Setelah itu keluar, lalu masuk dengan akun padukuhan.

C. Beranda Padukuhan
3

Beranda Padukuhan Mantup

Setelah masuk dengan akun padukuhan, Beranda langsung menampilkan Beranda Padukuhan Mantup. Di bagian atas ada 5 tab:

  • Ringkasan — cari warga se-padukuhan, angka seluruh padukuhan, tabel & grafik per RT (bisa Cetak / Excel), Pengingat se-padukuhan (HPL bulan ini, genap 1/15/17 tahun, usia sekolah, lansia) dan Cek Data se-padukuhan.
  • RT & Akun — kartu RT 01–17: jumlah warga, terakhir diperbarui (tanda merah bila ≥30 hari), akun-akunnya, tombol Buka data dan Buat akun.
  • Laporan — laporan gabungan Padukuhan Mantup.
  • Aktivitas — siapa mengubah apa, di RT mana.
  • Cadangan — cadangan harian & cadangan ke Google Drive.

Tombol Beranda RT .. membuka beranda RT yang sedang dibuka (sama seperti beranda Admin RT).

4

Membuat akun Admin RT

Tab RT & Akun → pada kartu RT klik Buat akun. Nama pengguna otomatis adminXX (mis. admin09). Pilih peran (Admin RT / Pengurus / Pembaca), isi kata sandi, Simpan. Berikan nama pengguna & kata sandi itu kepada pengurus RT tersebut — saat pertama masuk mereka wajib mengganti kata sandi.

5

Pindah membuka data RT lain

Di menu samping ada kotak kuning “Buka data [RT ..]”. Pilih RT, lalu semua menu (Data Warga, Keluarga, Laporan, dll.) menampilkan data RT itu. Data yang ditambahkan masuk ke RT yang sedang dibuka. Bisa juga lewat tombol Buka data pada kartu RT (tab RT & Akun).

Yang dikerjakan sistem: setiap perubahan oleh Admin Padukuhan tercatat di Riwayat Perubahan RT tersebut dengan nama Admin Padukuhan.
D. Laporan gabungan Padukuhan Mantup
6

Pilih “Gabungan PADUKUHAN MANTUP”

Buka laporan dari menu Laporan atau dari tab Laporan di Beranda Padukuhan. Di atas laporan ada pilihan RT .. / Gabungan PADUKUHAN MANTUP. Untuk laporan rekap, setiap RT menjadi satu baris dan baris terakhir adalah JUMLAH padukuhan. Klik angka untuk melihat nama-namanya.

7

Laporan daftar nama: ada kolom RT

WUS, PUS, Anak 6–18, Penduduk 15–59, Register Kelahiran, dan Pencatatan Ibu Hamil/KB menampilkan semua RT berurutan dengan kolom RT. Pilihan RT di kotak pengaturan bisa dipakai untuk menampilkan satu RT saja. Tombol Cetak / PDF dan Excel bekerja seperti biasa.

Laporan gabungan tersedia untuk: Rekap Catatan Data & Kegiatan (RT), Rekapitulasi Ibu Hamil/Melahirkan/Nifas, Inventarisasi Kampung KB (isian manual = jumlah semua RT), WUS, PUS, Anak 6–18, Penduduk 15–59, Register Bayi Lahir & Kematian, Pencatatan Ibu Hamil/KB/PUS. Laporan per keluarga/per dasawisma tetap dibuat per RT.

E. Kirim data lewat file (untuk RT yang offline)
8

Admin RT: Impor / Ekspor → Ekspor data RT

Menghasilkan satu file, mis. RT09_2026-11-07.siwarga. Kirim lewat WhatsApp atau flashdisk ke Admin Padukuhan.

9

Admin Padukuhan: Impor file data RT → periksa pratinjau → Terapkan

Sebelum disimpan tampil ringkasan: Baru, Berubah, Sama, Server lebih baru (tidak ditimpa), dan Hanya di server (tidak dihapus kecuali dicentang). Hanya RT pada file yang diperbarui.

Yang dikerjakan sistem: sebelum impor, server menyimpan cadangan otomatis (5 terakhir per RT). Bila keliru, buka Impor / Ekspor → Cadangan otomatis → Kembalikan. Admin RT hanya bisa mengimpor file RT-nya sendiri.
F. Tanpa internet (offline)
10

Pasang di HP & tetap bisa dibuka tanpa sinyal

Buka alamat aplikasi di Chrome HP → menu ⋮ → Tambahkan ke layar utama. Setelah pernah masuk sekali (online), aplikasi bisa dibuka walau tanpa internet: data terakhir tetap tampil, ikon awan dicoret dan tertulis Offline · N menunggu bila ada perubahan yang belum terkirim.

Yang dikerjakan sistem: perubahan disimpan di HP dan dikirim otomatis begitu internet tersambung lagi. Jangan menekan Keluar selama masih ada perubahan yang menunggu (sistem akan menolak supaya data tidak hilang). Pindah RT (Admin Padukuhan) hanya bisa saat online.
G. Saat memperbarui server di cPanel

1) Cadangkan folder data (isi database) dulu. 2) Hapus dist, server, app.cjs, package.json lama. 3) Upload & Extract zip baru. 4) RESTART di Setup Node.js App. Database lama otomatis diubah menjadi multi-RT (semua data lama = RT 08) tanpa ada yang hilang.

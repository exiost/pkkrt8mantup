Kata sandi disimpan teracak di server, jadi tidak bisa "dilihat" siapa pun — yang bisa dilakukan adalah mengatur kata sandi baru. Siapa yang bisa menolong tergantung akun yang lupa:

A. Cara biasa — lewat aplikasi (tanpa cPanel)
1

Yang lupa: hubungi admin

Bila muncul tulisan “Nama pengguna atau kata sandi salah”, jangan terus mencoba — setelah 8 kali salah, akun ditahan 15 menit. Hubungi Admin RT atau Admin Padukuhan.

2

Admin membuka daftar Pengguna

Admin masuk → menu Pengaturan → tab Akun & Server → bagian Pengguna. Admin RT melihat akun RT-nya; Admin Padukuhan melihat akun semua RT (beserta label RT-nya). Di sini juga terlihat nama pengguna setiap orang (tulisan @nama).

3

Klik ✏️ (Ubah) → isi kata sandi baru → Simpan

Pada akun yang lupa, klik ikon pensil ✏️. Isi Kata sandi baru (minimal 8 huruf/angka), pastikan Akun aktif menyala, lalu Simpan. Beri tahu kata sandi itu kepada pemilik akun.

Yang terjadi: karena kata sandinya diatur orang lain, pemilik akun wajib menggantinya saat masuk berikutnya (langkah 4).
B. Masuk setelah kata sandi diatur ulang
4

Ganti kata sandi dulu

Masuk dengan nama pengguna & kata sandi dari admin. Muncul layar “Ganti kata sandi dulu”: kotak pertama sudah terisi, isi Kata sandi baru dua kali (harus berbeda dari yang lama), tekan Simpan & masuk. Selesai — catat kata sandi baru di tempat aman.

C. Cara darurat — lewat cPanel (bila semua Admin Padukuhan lupa)

Hanya bisa dilakukan orang yang punya akses cPanel hosting, jadi tetap aman. Halaman cPanel dijelaskan dengan tulisan (tampilannya bisa sedikit berbeda tergantung hosting).

5

Pasang paket SIWARGA terbaru

Cara darurat ini ada mulai paket 10 November 2026. Bila server belum memakai paket itu, pasang dulu (cadangkan folder data → hapus dist, server, app.cjs, package.json → Upload & Extract zip). Memasang paket tidak perlu login aplikasi.

6

Buat file reset-admin-desa.txt di folder data

  1. cPanel → File Manager → buka folder data: pemerintahkota.id/data-warga/data (folder yang berisi siwarga.db).
  2. Klik + File, beri nama persis reset-admin-desa.txt, klik Create New File.
  3. Klik kanan file itu → Edit, tulis satu baris lalu Save Changes:

Pilihan 1 — reset semua akun Admin Padukuhan (cukup kata sandi baru, minimal 8 karakter):

MantupAman2026

Pilihan 2 — reset satu akun tertentu (nama pengguna, titik dua, kata sandi baru), misalnya Admin RT 08:

admin: MantupAman2026
Yang terjadi: bila belum ada akun Admin Padukuhan sama sekali, Pilihan 1 sekaligus membuat akun baru bernama padukuhan.
7

RESTART aplikasi

cPanel → Setup Node.js App → pada aplikasi data-warga klik RESTART. Server membaca file itu sekali saat menyala.

8

Buka lagi file itu — baca hasilnya

Isi file berubah menjadi laporan. Bila BERHASIL, isinya kurang lebih:

BERHASIL (10/11/2026, 17.37.55). Kata sandi akun berikut sudah diganti dengan yang Anda tulis:
  - desa (Admin Padukuhan)
Masuk dengan nama pengguna di atas, lalu Anda diminta membuat kata sandi baru.
Setelah berhasil masuk, HAPUS file ini.

Nama di daftar itu (contoh: desa) adalah nama pengguna untuk masuk — jadi cara ini juga menjawab bila lupa nama pengguna. Kata sandi tidak ditulis ulang di file.

Bila GAGAL, alasannya tertulis, misalnya:

  • GAGAL … kata sandi baru minimal 8 karakter → tulis kata sandi yang lebih panjang.
  • GAGAL … nama pengguna "…" tidak ada. Nama pengguna yang ada: … → pilih salah satu nama di daftar itu.

Perbaiki isi file (hapus tulisan GAGAL, tulis satu baris baru), lalu RESTART lagi.

9

Masuk, ganti kata sandi, lalu hapus file

Masuk dengan nama pengguna dari laporan + kata sandi yang Anda tulis → layar “Ganti kata sandi dulu” (seperti langkah 4) → buat kata sandi baru. Setelah berhasil, kembali ke File Manager dan hapus file reset-admin-desa.txt.

Yang terjadi: file yang sudah bertuliskan BERHASIL/GAGAL tidak diproses ulang walau server di-RESTART lagi, jadi tidak berbahaya bila lupa dihapus — tetapi sebaiknya tetap dihapus.
D. Supaya tidak terulang
  • Buat Admin Padukuhan kedua sebagai cadangan: Pengaturan → Akun & Server → Pengguna → Tambah → peran admin, wilayah Admin Padukuhan.
  • Catat nama pengguna & kata sandi Admin Padukuhan di tempat aman (buku catatan, orang kepercayaan).
  • Setiap RT sebaiknya punya lebih dari satu akun admin/pengurus.
Penting: jangan bagikan kata sandi lewat grup WhatsApp umum. Akses cPanel sama berharganya dengan kata sandi Admin Padukuhan — siapa pun yang memegang cPanel bisa mengatur ulang kata sandi.

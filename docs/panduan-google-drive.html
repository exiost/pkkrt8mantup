CADANGAN OTOMATIS KE GOOGLE DRIVE

Dikerjakan olehAdmin Desa (akun desa)Waktu±5 menit, sekali sajaPerangkatsebaiknya laptop / komputer

Setelah dipasang, setiap hari jam 01.00–02.00 WIB Google mengambil salinan seluruh database (semua RT & akun) dari server dan menyimpannya di folder “Cadangan SIWARGA” di Google Drive Anda. File yang lebih tua dari 60 hari dibuang otomatis ke Sampah Drive. Ini tambahan dari cadangan harian di server (14 hari), jadi data aman walau server bermasalah.

Sebelum mulai: pastikan paket SIWARGA terbaru sudah dipasang di server, dan Anda punya akun Google (Gmail). Gambar di panduan ini hanya dari aplikasi SIWARGA; halaman Google dijelaskan dengan tulisan, dan tampilannya bisa sedikit berbeda tergantung bahasa & versi.
A. Ambil skrip dari SIWARGA
1

Buka menu Kelola RT (Desa)

Masuk dengan akun Admin Desa. Di menu samping (di HP: tombol ☰ ungu kanan atas) pilih Kelola RT (Desa), lalu gulir ke paling bawah.

2

Kotak “Cadangan otomatis ke Google Drive” → tekan Salin skrip

Kotak ini berisi langkah singkat, kunci rahasia, dan tombol Salin skrip. Tekan Salin skrip sampai muncul tulisan hijau “Skrip disalin”.

Yang terjadi: skrip berisi alamat server dan kunci rahasia Anda. Jika tombol salin tidak berfungsi, buka Lihat isi skrip, klik di dalam kotak teks, tekan Ctrl+A lalu Ctrl+C.
B. Pasang skrip di Google
3

Buka script.google.com

Buka https://script.google.com di browser, masuk dengan akun Google yang ingin dipakai menyimpan cadangan. Klik Proyek baru (New project). Akan terbuka halaman editor berisi tulisan function myFunction() { }.

Agar mudah dikenali, klik judul “Proyek tanpa judul” di kiri atas dan ganti menjadi Cadangan SIWARGA.

4

Tempel skrip lalu Simpan

  1. Klik di kotak editor, tekan Ctrl+A lalu Delete untuk menghapus isi lama.
  2. Tekan Ctrl+V untuk menempel skrip dari SIWARGA.
  3. Klik ikon Simpan 💾 (atau Ctrl+S).
5

Jalankan “pasangJadwalHarian” satu kali

Di baris tombol atas editor ada kotak pilihan nama fungsi. Pilih pasangJadwalHarian, lalu klik Jalankan (Run) ▶.

Yang terjadi: fungsi ini memasang jadwal harian dan langsung membuat cadangan pertama. Menjalankannya dua kali tidak membuat jadwal dobel.
6

Berikan izin (hanya pertama kali)

Google akan meminta izin karena skrip perlu mengambil file dari internet dan menyimpannya ke Drive:

  1. Klik Tinjau izin (Review permissions).
  2. Pilih akun Google Anda.
  3. Bila muncul “Google belum memverifikasi aplikasi ini”: klik Lanjutan (Advanced) → Buka Cadangan SIWARGA (tidak aman).
  4. Klik Izinkan (Allow).

Peringatan “tidak aman” muncul karena skrip ini buatan sendiri, bukan aplikasi yang didaftarkan ke Google. Skrip hanya mengambil file cadangan dari server SIWARGA dan menyimpannya di folder Cadangan SIWARGA milik Anda.

7

Periksa hasilnya

Di bawah editor muncul Log eksekusi; tunggu sampai tertulis Eksekusi selesai (Execution completed). Lalu buka Google Drive: ada folder Cadangan SIWARGA berisi file siwarga-tahun-bulan-tanggal.db. Selesai — mulai besok berjalan sendiri.

Untuk melihat jadwalnya: di menu kiri editor klik ikon jam ⏰ Pemicu (Triggers) — ada satu baris cadangkanSiwarga, setiap hari.

D. Memakai file cadangan dari Drive

File siwarga-….db adalah salinan utuh database. Untuk mengembalikan data server ke tanggal tertentu:

  1. Unduh file tanggal yang diinginkan dari Google Drive.
  2. cPanel → Setup Node.js App → STOP APP.
  3. File Manager → folder data: ganti nama siwarga.db menjadi siwarga-lama.db, hapus siwarga.db-wal dan siwarga.db-shm bila ada.
  4. Unggah file dari Drive ke folder data dan beri nama siwarga.db.
  5. START APP / RESTART, lalu buka aplikasi dan tekan Ctrl+F5.
